# Zsh и Oh My Zsh: устройство современной командной оболочки

## 1. Командная оболочка: что это и зачем её менять

Когда вы открываете терминал, вы видите строку приглашения и можете вводить команды.
Программа, которая принимает эти команды, передаёт их системе и показывает результат,
называется **командной оболочкой** (shell).

В большинстве дистрибутивов Linux по умолчанию стоит **Bash** (Bourne Again SHell).
Он появился в 1989 году и с тех пор стал стандартом. Bash надёжен, предсказуем и
умеет всё, что нужно для работы: переменные, циклы, функции, автодополнение файлов.
Но за 35 лет у него практически не изменился пользовательский интерфейс — та же
чёрно-белая строка, минимум визуальной обратной связи.

**Zsh** (Z Shell) появился в 1990 году и долгое время был просто «ещё одной оболочкой».
Перелом произошёл с появлением **Oh My Zsh** — фреймворка, который сделал настройку
Zsh простой и доступной. Сегодня это стандарт де-факто для разработчиков.

## 2. Zsh: надстройка над Bash, а не замена

Zsh полностью обратно совместим с Bash. Любой скрипт `.sh`, написанный для Bash,
выполнится в Zsh без изменений. Все привычные команды (`ls`, `cd`, `grep`, `sudo`)
работают точно так же.

Разница — в интерактивном режиме. Когда вы работаете в терминале вручную, Zsh
предлагает возможности, которых в Bash нет или они требуют сложной настройки.
### 2.1 Автодополнение с меню

Bash умеет дополнять имена файлов и команд по Tab. Zsh идёт дальше:

- Показывает **меню с вариантами**, а не просто подставляет первый попавшийся.
- **Дополняет опции команд**: набираете `git `, жмёте Tab — видите список доступных подкоманд.
- **Дополняет пути с фильтрацией**: `cd ~/D` → Tab → покажет только папки на D, а не все файлы.
- Поддерживает **рекурсивное дополнение**: `**/file` найдёт file в любой вложенной папке.
### 2.2 Глобирование (расширенные маски)

Bash: `*.txt` — все txt-файлы в текущей папке.
Zsh:

- `**/*.txt` — рекурсивно во всех подпапках.
- `*.txt~*.bak` — все txt, исключая bak.
- `*.(txt|md)` — все txt и md.
- `<1-100>.*` — файлы с числом от 1 до 100 в имени.
### 2.3 Подсветка синтаксиса и автоподсказки

При подключении плагинов (см. раздел 3) Zsh подсвечивает команду зелёным, если
она корректна, и красным, если нет — **до нажатия Enter**. А серая подсказка
из истории позволяет не набирать длинные команды повторно.
## 3. Oh My Zsh: платформа для управления Zsh

**Oh My Zsh** — это фреймворк с открытым исходным кодом (лицензия MIT), созданный
в 2009 году. Он решает главную проблему Zsh: сложность первоначальной настройки.
### 3.1 Что даёт Oh My Zsh

| Компонент            | До Oh My Zsh                              | После                                      |
| :------------------- | :---------------------------------------- | :----------------------------------------- |
| Управление темами    | Писать функцию `PROMPT` вручную           | Одна строка `ZSH_THEME="..."` в конфиге    |
| Управление плагинами | Клонировать репозитории, править `$fpath` | Одна строка `plugins=(...)` в конфиге      |
| Алиасы               | Прописывать каждый отдельно               | Готовые наборы: git, docker, rails, python |
| Обновления           | Ручное отслеживание                       | `omz update`                               |
### 3.2 Как устроен Oh My Zsh

Всё хранится в `~/.oh-my-zsh/`. Структура:
~/.oh-my-zsh/
├── lib/           # Ядро: загрузка конфигурации, комплитера, тем
├── plugins/       # Встроенные плагины
├── custom/
│   ├── plugins/   # Пользовательские плагины
│   └── themes/    # Пользовательские темы
└── themes/        # Встроенные темы

### 3.3 Важные плагины
- **git** — десятки коротких алиасов (`gst` = `git status`, `gco` = `git checkout`,  
    `gcm` = `git commit -m`). Плюс функция `git_prompt_info`, которую используют все темы.
    
- **zsh-autosuggestions** — серая подсказка из истории. `→` (стрелка вправо) — принять,  
    `Ctrl+E` — принять и дополнить, `Ctrl+/` — отменить.
    
- **zsh-syntax-highlighting** — подсветка синтаксиса в реальном времени. Зелёный =  
    команда существует и синтаксис корректен. Красный = ошибка или неизвестная команда.
    

## 4. Powerlevel10k: тема как интерфейс

Powerlevel10k — тема для Zsh/Oh My Zsh, написанная с нуля для максимальной скорости.  
Автор: Роман Перепелица, 2019 год.
### 4.1 Почему не другие темы

Большинство тем (включая популярную Powerlevel9k) вычисляют строку приглашения  
каждый раз при нажатии Enter. Если Git-репозиторий большой или плагинов много,  
возникает заметная задержка.
Powerlevel10k решает это двумя механизмами:

- **Instant Prompt** — строка появляется мгновенно при запуске терминала, не дожидаясь  
    загрузки всех плагинов. Плагины грузятся в фоне, и когда готовы — строка обновляется.
    
- **Gitstatus** — вместо медленных вызовов `git status` используется демон `gitstatusd`,  
    который кеширует состояние репозитория и обновляет его асинхронно.
### 4.2 Интерактивный мастер

Вместо правки конфигурационного файла Powerlevel10k предлагает мастер `p10k configure`.  
Он показывает варианты оформления в реальном времени и записывает выбор в `~/.p10k.zsh`.
### 4.3 Transient Prompt

Когда эта опция включена, после выполнения команды полноценная строка приглашения  
заменяется на простую `❯`. История терминала становится чистой: только команды,  
без повторяющегося оформления. При копировании последовательности команд из истории  
не нужно вычищать строки приглашения.

### 4.4 Информационные сегменты

Powerlevel10k показывает в строке:

- **os_icon** — иконка дистрибутива (определяет по `/etc/os-release`).
    
- **dir** — текущая папка. Длинные пути умно сокращает.
    
- **vcs** — статус Git: ветка, коммиты впереди/позади remote, staged/unstaged/untracked  
    изменения, stash, конфликты.
    
- **status** — код возврата последней команды (красный = ошибка).
    
- **command_execution_time** — сколько выполнялась последняя команда (если дольше порога,  
    по умолчанию 3 секунды).
    
- **time** — текущее время.
    
- **background_jobs** — фоновые задачи.
    

Сегменты можно добавлять и убирать в `~/.p10k.zsh`.
## 5. Nerd Font: почему иконки работают

Powerlevel10k использует символы из частной области Unicode (Private Use Area).  
Эти символы не входят в стандартные шрифты. **Nerd Font** — проект, который добавляет  
в популярные моноширинные шрифты (Fira Code, Hack, JetBrains Mono) тысячи иконок из  
наборов Font Awesome, Devicons, Octicons, Material Design Icons.

Без Nerd Font вместо иконок отображаются квадратики или пустые места.  
С ним — иконка дистрибутива, значок папки, символ Git, иконка часов и т.д.
## 6. Сравнение: Bash без настройки vs Zsh + Oh My Zsh

|Аспект|Bash (чистый)|Zsh + Oh My Zsh + P10k|
|---|---|---|
|Строка приглашения|`user@host:~$`|Иконки, Git, время, статус|
|Автодополнение|Tab по файлам|Меню, опции команд, фильтрация|
|Подсказки|Нет|Из истории, серым цветом|
|Подсветка|Нет|Зелёный/красный онлайн|
|Алиасы Git|Вручную|100+ готовых|
|История команд|Обычный список|Общая по всем сессиям|
|Скорость запуска|Быстро|Мгновенно (Instant Prompt)|
|Настройка|Писать функции|Мастер `p10k configure`|

## 7. Когда не нужен Zsh

- Если вы работаете на десятках серверов, где Bash — единственная доступная  
    оболочка, и хотите единообразия.
    
- Если пишете скрипты, которые должны быть максимально переносимыми  
    (Bash гарантированно есть везде).
    
- Если терминал используется редко и некритично.
    

Во всех остальных случаях переход оправдан.

## Резюме

Zsh — это Bash с современным пользовательским интерфейсом. Oh My Zsh — платформа,  
которая делает настройку Zsh тривиальной. Powerlevel10k — тема, которая превращает  
строку приглашения в информативную панель. Вместе они дают профессиональный инструмент  
без ущерба для совместимости и скорости.

Весь конфиг восстанавливается тремя файлами: `~/.zshrc`, `~/.p10k.zsh` и папкой  
`~/.oh-my-zsh`. Перенос на другую машину — скопировать эти три элемента и установить Zsh.
